# 8B vs 30B-A3B benchmark — 2026-09-18

Question: which VLM should back local detection, and is the 30B worth renting a
GPU for as a "quality tier"? All numbers below are from the 8-fixture oracle
(`eval/fixtures` + `eval/oracle`), scored by the honest matcher
(`eval/scoring.mjs`, head-noun agreement + optimal bipartite assignment). No
cloud money was spent; the 30B ran on the existing Tailscale nixos box (CPU).

- Latency: 8B ~188s/photo, 30B was ~327s/photo on this M4 Pro (Sep 5).

## Raw single-shot (controlled model-vs-model)

Same harness prompt, direct Ollama, no tiling/audit. 30B leads 8B by +4–7pp in
both eras (59.4% fresh-nixos vs 55.2% fresh-Mac; 62.2% July-Mac re-scored),
consistent under today's matcher. Raw scores are far below production because
single-shot lacks tiling + audit — use them only head-to-head, never as the
production claim. nixos CPU latency (1007s/photo) reflects the box, not the
model; on the L40S FP8 the same calls are ~3–6s.

## Caveats

- Historical 30B production runs (Sep 5) were validated by re-scoring saved runs
  with today's matcher (`node eval/rescore.mjs`) — 79.3% confirmed, delta +0.0.
- The July 30B raw run lacks `mockup_living_01` (fixture added later), n=7.
- 8B run variance is high (±6pp); a re-run before any final quality-tier A/B
  decision is advised. The quality tier itself must be validated with
  `make eval` pointed at it before it is called an improvement (repo rule).

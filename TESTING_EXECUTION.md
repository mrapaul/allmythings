## Testing Best Practices

### 1. Test Organization

```
api-service/
├── src/
│   ├── services/
│   │   └── __tests__/service.test.ts    ✅ Collocated tests
│   └── adapters/
│       └── __tests__/adapter.test.ts    ✅ Organized by layer
└── tests/
    ├── unit/                            ✅ Pure logic tests
    ├── integration/                     ✅ Component interaction
    └── fixtures/                        ✅ Test data

mobile-app/
├── lib/
│   ├── domain/
│   │   └── models/
│   └── data/
│       └── repositories/
└── test/
    ├── domain/                          ✅ Model tests
    ├── data/                            ✅ Repository tests
    └── fixtures/                        ✅ Test data
```

### 2. Mocking Strategies

```typescript
// API: Mock external services
jest.mock('@/adapters/google-vision', () => ({
  GoogleVisionAdapter: jest.fn(),
}));

// Flutter: Dependency injection
final mockDetectionService = MockDetectionService();
final repository = InventoryRepository(
  detectionService: mockDetectionService,
);
```

### 3. Test Isolation

```typescript
// ✅ Good: Each test is independent
describe('Detection Service', () => {
  let service: DetectionService;

  beforeEach(() => {
    service = new DetectionService(mockVision);
  });

  it('detects objects', async () => {
    const result = await service.detect(image);
    expect(result).toHaveLength(> 0);
  });
});

// ❌ Bad: Tests depend on execution order
describe('Detection Service', () => {
  let service: DetectionService;
  let results: Detection[];

  it('initializes service', () => {
    service = new DetectionService();
  });

  it('detects objects', async () => {
    // Service may not be initialized!
    results = await service.detect(image);
  });
});
```

### 4. Golden Files (Flutter)

```dart
// Create golden baseline
flutter test --update-goldens

// Commit baseline
git add test/widgets/goldens/*.png

// CI validates against baseline
// Update only when intentional
flutter test  // Fails if UI changed
```

## Troubleshooting

### API Coverage Below Target

**Symptom**: `Coverage: 75.3% (target: 80%)`

**Solution**:
1. Identify uncovered files
   ```bash
   cd api-service
   npm run test:coverage
   # Look for files with red highlighting
   ```

2. Add tests for missing coverage
   ```typescript
   // Example: Add edge case test
   test('handles empty input', () => {
     const result = detector.detect([]);
     expect(result).toEqual([]);
   });
   ```

3. Re-run coverage
   ```bash
   npm run test:coverage
   ```

### Mobile Tests Failing at Build Generation

**Symptom**: `flutter pub run build_runner build` fails

**Solution**:
```bash
# 1. Clean previous build
flutter clean

# 2. Get dependencies
flutter pub get

# 3. Run code generation with verbose output
flutter pub run build_runner build --verbose --delete-conflicting-outputs

# 4. Check for compilation errors in generated files
# Fix any issues in source files that generated code depends on
```

### GitHub Actions Timeout

**Symptom**: `Job timeout after 30 minutes`

**Solution**:
1. Check slow tests
   ```bash
   npm run test -- --reporter=verbose
   ```

2. Parallel execution
   ```bash
   # Check vitest.config.ts pool settings
   pool: 'threads'  # Use threading
   singleThread: false
   ```

3. Increase timeout in workflow
   ```yaml
   timeout-minutes: 40  # Increase from 30
   ```

## Performance Optimization

### Speed Up Tests

**API Service**:
```typescript
// Use in-memory database for tests
process.env.DATABASE_URL = 'sqlite::memory:';

// Parallel execution
pool: 'threads'
poolOptions: { threads: { singleThread: false } }
```

**Flutter**:
```bash
# Run tests in parallel
flutter test -j 4

# Run only changed tests
flutter test test/domain/
```

### Coverage Overhead
- API coverage adds ~10% to test time
- Mobile coverage adds ~20% to test time
- E2E adds ~15 minutes per run

**Optimization**: Run coverage only on main/develop branches
